Project Title

Students & Courses API

Description

This is a RESTful API built with Node.js, Express, and MongoDB that allows users to perform CRUD operations on two collections: students and courses. The project includes:

Fully functional GET, POST, PUT, DELETE endpoints for both collections

Data validation and error handling to ensure reliable API responses

OAuth 2.0 authentication to secure routes and manage user access

Swagger API documentation for easy testing and exploration of all endpoints

Integration with MongoDB for persistent data storage

A clean project structure separating routes, controllers, and Swagger docs

This project is designed as a beginner-friendly full-stack backend project, demonstrating API development, secure authentication, database interaction, and documentation best practices. It’s deployed online and can be accessed through its live URL.

Features

Manage students: add, update, delete, and fetch student data

Manage courses: add, update, delete, and fetch course data

Protected routes using OAuth 2.0 authentication

Interactive Swagger documentation

Data validation and error handling
